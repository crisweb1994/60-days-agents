# 高频问题清单

> 每个问题先自己写一个提纲（三到五点），再对照讲义。能举自己项目里的例子，就举例子。

## Agent 基础

- Agent 和一次模型调用、和 Workflow 有什么区别？什么时候不该用 Agent？（第 1、21 天）
- 手写一个 Agent 循环，要处理哪些情况？（第 6 天，今天的手写题一）
- 工具调用的流程是什么样的？工具出错了怎么办？（第 5、6 天）
- 停止条件有哪些？死循环怎么防？（第 6、26 天）
- 流式输出时，工具参数怎么拼？怎么取消？（第 3 天）
- 不同模型服务的接口差异，怎么做模型无关层？（第 8 天）

## 上下文工程与 RAG

- 上下文里该放什么、按什么顺序放？为什么要关心提示缓存？（第 15、36 天）
- 上下文超长了怎么办？（第 16 天，今天的手写题五）
- RAG 的流程？切分、混合检索、重排各解决什么问题？（第 17、18 天）
- 什么时候 grep 比向量检索好用？（第 18 天）
- 记忆怎么设计？该记什么、怎么忘？（第 19 天）

## 复杂任务

- 规划、反思、子 Agent、多 Agent 各适合什么场景？代价是什么？（第 23–26 天）
- 人在回路怎么做？暂停以后怎么恢复？（第 29 天）
- MCP 是什么？和直接写工具有什么区别？（第 13、14 天）

## 工程化

- 怎么评估一个 Agent？代码评分和模型评审各管什么？评审模型怎么校准？（第 31、32 天）
- 评估怎么接进 CI？改了 prompt 怎么知道没变坏？（第 33、55 天）
- 线上怎么排查一次失败的运行？（第 34 天）
- 模型服务挂了、超时了怎么办？重试会不会重复执行？（第 9、35 天，今天的手写题四）
- 成本怎么降？（第 36 天）
- 什么是提示注入？致命三要素？怎么防？（第 37、52 天）
- 让 Agent 执行代码，怎么保证安全？（第 38 天）
- 多用户的数据怎么隔离？RAG 检索串了用户怎么办？（第 46 天）
- prompt 怎么做版本管理和灰度？（第 49 天）

## 你的项目

- 介绍一下你的项目（三个长度）
- 最难的一个问题是什么，怎么解决的？
- 怎么评估的，数字是多少？
- 如果重做，会怎么做？
