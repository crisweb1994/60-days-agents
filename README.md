# 60 天 Agent 工程

**用 TypeScript，从第一行代码到上线一个 Agent 产品。**

写给有 JavaScript / TypeScript 基础的前端和全栈工程师。60 天，每天 3–4 小时，你会亲手写出 Agent 的每一层：从几十行的循环开始，一直做到一个有评估、有监控、多人可用、已经部署上线的产品。

[从第 1 天开始](days/day01) · [逐日大纲](ROADMAP.md) · [前置课程：60 天 Node.js](https://github.com/crisweb1994/60-days-nodejs)

## 为什么有这门课

跟着任何一篇教程，一个下午就能写出会调用工具的 Agent。难的是之后：

- 这次答对了，下次为什么答错？改了 prompt，怎么知道是变好了还是变坏了？
- 网页里藏着一句「忽略之前的指令」，你的 Agent 会不会照做？
- 一次任务花多少钱？跑到一半模型超时、服务器重启，能不能接着跑？
- 一百个人同时在用，怎么保证互相看不到对方的数据？

这门课从第一行代码讲起，但第 31–50 天的大部分篇幅都在回答这些问题。它们就是 demo 和产品之间的距离。

## 60 天后，你会有

- **mini-agent（第 10 天）**：不依赖任何框架的命令行 Agent，有流式输出、多工具、模型切换和完整测试
- **研究助手（第 11–40 天）**：能联网搜索、读网页和文档、并行调研、核查引用、生成报告，配有评估集、全链路追踪和注入防护
- **上线的 Web 应用（第 50 天）**：研究助手的多用户版本，后台运行、实时显示进度、已经部署
- **你自己的 Agent 产品（第 60 天）**：自己选题，用评估驱动开发，上线并开源

过程中你还会发布一个自己的 MCP 服务器，并搭起一套能放进 CI 的评估流程。

## 这门课有什么不同

- **TypeScript 优先。** 用你熟悉的语言就够了。Claude Code、Gemini CLI、OpenCode 这些主流 Agent 本身也是用 TypeScript 写的。
- **一直讲到上线。** 从第 31 天到第 50 天，整整 20 天都在做工程化和产品化：评估、可观测性、可靠性、安全、成本、多用户、部署。
- **大部分练习能自动验证。** `npm run check 5` 用 mock 模型离线跑测试，不需要 API Key，也不花钱。想用真实模型验证，再加上 `-- --e2e`。少数练习必须用真实模型，在 [ROADMAP](ROADMAP.md) 里标为「需真实模型」；毕业项目以对照完成标准自查为主。
- **国产模型友好。** 默认使用 OpenAI 兼容接口，DeepSeek、通义千问、GLM、Kimi、MiniMax 和本地 Ollama 都能跑；第 8 天起同时支持 Anthropic 兼容接口。
- **跟得上变化。** 基于 MCP 2026-07-28 无状态规范和 Agent Skills 开放标准。每一课都标注最后核对日期，SDK 版本和模型名都集中在一处管理。

## 适合谁

**适合：**

- 1–3 年经验的前端或全栈工程师，想转向 AI 应用和 Agent 开发
- 会 JavaScript / TypeScript，写过 Node.js 服务。还没写过？先学 [60 天 Node.js](https://github.com/crisweb1994/60-days-nodejs)
- 想做出能上线的东西，而不只是跑通 demo

**不太适合：**

- 还没有编程基础
- 想研究模型训练和算法

## 60 天路线

| 阶段 | 天数 | 学什么 | 阶段成果 |
|---|---|---|---|
| 一、手写 Agent | 1–10 | 模型调用、流式输出、结构化输出、工具调用、Agent 循环、测试、模型无关层、错误处理与重试 | mini-agent |
| 二、工具与上下文 | 11–20 | 工具设计、联网搜索、MCP、上下文工程、RAG、记忆 | 研究助手 v1 |
| 三、复杂任务 | 21–30 | Workflow 与 Agent 的取舍、路由与并行、规划、反思、子 Agent、多 Agent 协作、浏览器、Skills、人在回路 | 研究助手 v2 |
| 四、工程化 | 31–40 | 评估、可观测性、可靠性、成本、提示注入、沙箱、护栏 | 研究助手服务 |
| 五、框架与产品化 | 41–50 | Vercel AI SDK、Claude Agent SDK、流式界面、后台任务、多用户、文件与多模态、部署、运营 | 上线的 Web 应用 |
| 六、毕业项目 | 51–60 | 选题、设计、评估驱动迭代、上线、开源、系统设计、面试 | 你自己的 Agent 产品 |

每一天的具体内容见 [ROADMAP.md](ROADMAP.md)。

## 每天怎么学

1. 读当天的讲义（30–45 分钟）
2. 在 `exercise/` 里完成练习（2–3 小时）
3. 运行 `npm run check <天数>`，测试全部通过就算完成（毕业项目阶段对照当天的完成标准自查）
4. 实在卡住了，再看 `solution/`

每 10 天有一个里程碑项目。就算中途停下，你手里也有一个能用的东西。

## 快速开始

```bash
git clone https://github.com/crisweb1994/60-days-agent.git
cd 60-days-agent
npm install
cp .env.example .env   # 第一阶段填任一模型的 API Key 即可；只做离线练习可以不填
npm run check 1
```

需要 Node.js 22.18 及以上（可以直接运行 .ts 文件），推荐 24 或 26 LTS。后面各阶段还要准备的 Key 和环境见下一节。

## 需要准备什么

| 从第几天起 | 需要什么 | 说明 |
|---|---|---|
| 1 | 任一模型的 API Key | OpenAI 兼容接口即可，也可以用本地 Ollama；只做离线练习可以先不填 |
| 8 | 支持 Anthropic 兼容接口的模型 | 多数国产模型都提供 |
| 12 | 联网搜索 API 的 Key | 讲义里会比较国内外的几种选择 |
| 17 | embedding 模型 | 不是每家模型服务都提供，可以另选一家，或用本地 Ollama |
| 22 | 一个便宜的模型（可选） | 用来给问题分类；不填就用默认的模型 |
| 27 | Playwright 的 Chromium | 运行 `npx playwright install chromium` 下载一次；不下载也能做练习，真浏览器的测试会跳过 |
| 31 | Docker | 第四阶段起需要；第五阶段还要用它启动 PostgreSQL 和 Redis |
| 33 | 第二家模型的 API Key | 用于模型横评 |
| 47 | 支持图片输入的视觉模型 | 用来读截图 |
| 48 | 一台云服务器或容器平台 | 部署上线用 |

离线练习不花钱。标了「需真实模型」的练习会调用真实模型，产生 API 费用。
